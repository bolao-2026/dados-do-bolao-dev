# Dados Públicos do Bolão (DEV)

> Esta é a versão DEV do repositório. Apenas para desenvolvimento
> e testes. Antes de iniciarmos o servidor pra valer, precisamos
> criar um repo equivalente a este vazio.

Este repositório contém os dados públicos gerados pelo servidor
do Bolão. A ideia é deixar públicos os palpites de todos os
usuários à medida que forem sendo encerrados os prazos para
palpites. O servidor fará a publicação de forma automática aqui e
na CDN (que contém a versão destes dados em formato e
configuração mais apropriadas para o aplicativo do Bolão).
